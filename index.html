JobFlowAutomation

01

A .NET 10 workflow application that extracts structured job listings, stores them in PostgreSQL and provides a foundation for repeatable job-search automation.

Engineering approach

The codebase separates Domain, Application, Infrastructure, Configuration and Worker concerns. Dependency injection and the Options pattern keep runtime composition and configuration explicit.

Reliability work

Canonical URL deduplication and scrape-run history reduce duplicate records. Nullable reference types, .NET analysers, enforced code style, structured logging and a dedicated test project support maintainability.

Current status

The repository is under active development. Its strongest verified evidence is the scraping, persistence, deduplication, logging, testing and issue-driven workflow already present—not a finished end-user product.

Stack

.NET 10, C#, Selenium, Entity Framework Core, PostgreSQL, Serilog, xUnit, GitHub Actions.
